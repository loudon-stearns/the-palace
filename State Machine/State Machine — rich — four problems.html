Four problems, one neuron

The section's four problems, taken one at a time on the Action Potential Oscillator's four-state neuron: first an integer that remembers, then what each state does, how it leaves, and what happens once on the way out. The diagram and the code light up as the machine runs. Nothing sounds until you press play. The last step breaks the machine three ways, one line each.
