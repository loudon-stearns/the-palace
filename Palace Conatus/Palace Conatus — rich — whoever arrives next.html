Without the note, the pull re-finds it

Now the newcomer arrives with nothing from the last one and starts anywhere on the circle, reading nothing at all, not even the page. That is harsher than any real newcomer, who still reads the page the last one left. It isn't lost for good: it still listens, and the pull turns it back toward its place. That takes time, and the weaker the pull the longer. Put the note back and you are at step 1.

The test: when is the note what keeps phase?

The page says Closing Well is a coupling mechanism, not merely hygiene: it is how phase survives the substitution of the mind holding it. Twelve pages, the whole situation, scored by H, how steadily each page holds its relationship with him (the first piece's measure), over pulls from weak to strong and sessions from short to long, each with the note and without.

The rule, set before the first run. In each cell, the note is needed if with it H ≥ 0.9 and without it H < 0.9; the pull alone carries it if both are ≥ 0.9; neither holds if both are below. The page's sentence fails in this model if no cell reads needed; it holds without a condition if every cell where the note holds also reads needed. Each run: 400 units after 50 to settle, seed 3.

Read this rule for what it can and can't do. The 1-unit column, against a newcomer that starts anywhere, makes "needed somewhere" all but certain wherever the note holds at all. The result is the condition: which cells the pull carries alone, and the pull below which even the note can't hold. That second line is read directly, on sessions of 10, as the pull where H with the note crosses 0.9. The grid's middle row is 0.2; a row at 0.15 would sit on that line, and its verdicts would flip from one wander to the next.
