A birth is a stack of files read in order before the first word of the task. Each step adds one idea and keeps the last. The steps are a path, not a gate: jump to any of them.

Tokens are Claude Code's own /context counts, except where marked ≈: characters scaled to Claude Code's count for the same file (2.82 a token, from CLAUDE.md's measured 3.0k at 635b9103).
