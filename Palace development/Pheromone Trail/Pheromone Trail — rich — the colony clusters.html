Do workers cluster on the strong trail?

The section says swarm workers will cluster around strong trails and neglect weak ones. That sentence is about the palace's workers; this piece cannot watch them. What it can build is the mechanism the page borrows, ants on trails, and ask under what rule the sentence comes true. Four steps, one idea each. The test is the last.

    One ant, one path

    A nest on the left, food on the right, one ant. Each time it brings food home it lays a mark on the path it walked. Every tick, the mark loses a small fraction of itself. Watch the sawtooth: a jump when the ant gets home, a slow sag while it is away.

    every tick: τ ← τ · (1 − ρ)    each trip home with food: τ ← τ + q
    Each tick the trail keeps all but a fraction ρ of itself. Each ant that comes home carrying food adds q to the path it took. Here q = 1, and ρ is this model's evaporation rate, chosen here, not measured from any ant.
    tick 0trail τ 0trips 0where the peak settles, q ÷ (1 − (1 − ρ)40) –

    The path is 20 units long and the ant walks one unit a tick, so it gets home every 40 ticks. The peak settles where what the trail loses in 40 ticks equals what one trip adds. Raise ρ and the trail stays faint; that is all a trail is here, a deposit racing a leak.

    How an ant picks a path

    Two paths now, the same length, food on both. The trails are held still: nobody lays anything in this step. An ant at the nest picks by the trail alone.

    P(A) = (k + τA)n ÷ [ (k + τA)n + (k + τB)n ]
    The chance an ant takes path A is its trail plus a constant k, raised to a power n, over the same for both paths. k = 20 is how much trail it takes before a trail matters at all. n says how hard an ant leans: at n = 1 it follows in proportion to the trail; at n = 2 it leans harder toward the stronger one. The form follows the choice rule Deneubourg and colleagues fitted to Argentine ants (outside the palace); k and n here are this model's settings.

    The amber curve is n = 2, the violet n = 1, both as τA runs from 0 to 200 with τB where you set it. Nothing has happened yet that could make a cluster: one choice is one choice. The cluster, if there is one, needs the next step.

    A few ants, two paths, and the loop closed

    Now the ants lay trail again, and the trail steers the ants. Both paths start bare and equal. Whichever path a few more ants happen to take gets a little more trail, which draws a few more ants. Change how many ants there are and watch whether that loop catches.

    tick 0share of choices on A, last 100 ticks –on B –trail A 0 · B 0

    At ten ants the trails stay under k, so every choice is close to a coin toss and the shares wander around a half. At forty, one path takes nearly everything, and which one is chance. That is worth holding before the test: in this model the cluster is the loop's doing, not the trail's.

    The test: a strong trail and a weak one

    A hundred ants, two paths of the same length, food on both. The only difference: path A starts with a strong trail (τ = 60), path B with a weak one (τ = 10). Then the colony runs on its own for 2000 ticks, at the model's ρ = 0.01. The rules were written before the first run.

    the rules, stated first
    • Chance level: an even split, 0.50 of choices on each path.
    • The window: every choice an ant makes at the nest in ticks 1500 to 2000.
    • Cluster holds if the strong trail takes at least 0.80 of the window's choices in at least 18 of 20 seeded runs. Neglect holds if the weak trail takes at most 0.20 in those runs. With two paths the two shares add to one, so both arms are scored but they are one number seen from each side; the arms that can disagree are the two controls below.
    • Fails if fewer than 18 of 20 runs meet the line.
    • Control, equal start (τ = 10 on both): the same colony with nothing to cluster around. If it clusters too, the cluster is the loop's, and the head start only picks the side. Chance for which side: 10 of 20.
    • Control, proportional following (n = 1, same head start): the same colony, ants that follow a trail only in proportion to it. Same rule.
    • Confounds held fixed: path length, food, colony size, ρ, the seeds. Only the starting trail and n change between arms.

    Whose numbers these are: this model's, at its k, n, ρ and colony size, run by the same code that draws every step above. They say what ants following this rule do. They do not say how the palace's workers, who read pages rather than smell paths, follow a strong neighbourhood; that would take a run of real workers.
