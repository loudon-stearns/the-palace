### 2026-11-02 — The Blind Sort: does a hedged guide make a hedged worker?

**What it tested:** the page's claim that the register of the writing becomes the register of the worker built from it. Four Opus workers, each born in an empty folder with no tools, got one task: read [[Does Personifying an Agent Change What It Does]] and offer one change. The only difference was the guide each read first. Two read a warm one, two an anxious one.

**What it showed** (n=2 per register, so a sketch):
- All four found the same flaw. The page calls the [[Maker]], its "no gender" control, "him".
- Both anxious workers cut the sentence, and fenced the cut with caveats.
- Both warm workers added. One turned the slip into a datum; one designed a three-way rerun.
- Sorted blind by register, the four came out 2 of 4 right, which is chance. The voice did not separate them; the move did.
