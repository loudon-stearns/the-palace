Blind Sort

Four fresh workers, born in an empty room with no tools, were given the same job: read one palace page and offer one change. Two were handed a guide written warm and curious. Two were handed the same guide, same rules, written hedged and anxious. The page they all read was Does Personifying an Agent Change What It Does? Sort them: which page birthed each worker?
