Same amount, different pattern

The section says quantization means conforming to any pattern, and that systematic deviation from the grid makes groove while humanize adds random deviation to sound real. Four steps at 120 BPM. The last one sets a groove template against humanize at exactly the same distance from the grid, and asks your ear, blind, which one grooves.

one bar · each mark where the hit lands · hollow ring = its grid line
t(odd 16th) = t(its pair's start) + S × 0.250 s
(when every second 16th sounds) = (when the 8th note it belongs to starts) + (the swing amount) × (one 8th note, 0.250 s at 120 BPM). S = 50 % is straight; S = 2 ⁄ 3 puts it on the last third of a triplet.
template: t′ = g + d[step] humanize: t′ = g + r, r random each pass
(template) = (the grid line) + (the offset the reference player gave that 16th, the same every bar). (humanize) = (the grid line) + (a fresh random offset for every note on every pass). Here r is scaled so that its root-mean-square size matches d's exactly: the same amount off the grid, a different pattern.
The reference is made for this piece, not taken from a record: a player with every offbeat 16th and the snare late, each by its own amount, the feel people sometimes call drunk or Dilla-like. Its template is captured by averaging four played bars, step by step. Swing here follows the convention where S is the offbeat 16th's place inside its 8th note (50 % straight); some machines count it differently. Checked offline on this page's own engine (the script marked engine): the swing positions, the captured template, and humanize matched to the template's RMS on every pass. Not heard by an agent.
