# Boundary-Crossing Instruments — Context

The body has not been edited since the palace's first commit, 2026-03-17 (`abc2592`), apart from the hero line (`fb2961f`). Every decision about this page so far was made in its frontmatter or on its neighbours.

## A breakthrough without the type

It was born typed `breakthrough`. The v1.17 Schema Ceremony of 2026-08-25 retired that type because no one had used it since June: "the type stopped being used, not the insight." Its nine pages were reassigned one by one, and this one became `concept` (`de5990e`). On 2026-10-24 the hub bar moved to the top inbound decile, and the page was one of twelve promoted to `hub` (`6c356eb`). No commit touched the word "breakthrough" in the body when the type changed, so the opening and the Cross-Pillar section still use it.

## The catalogue went to Dissolutions

The first forward vector, added in a weave's batch on 2026-04-07, promised "a growing catalogue of specific instances" (`1c96439`). On 2026-06-05 the weave created [[Dissolutions]], a catalogue of seven, on Loudon's gate (`b445ac0`). That day's compliance pass gave Dissolutions an `emerged-from` link to this page, "the breakthrough that first named the pattern" (`4293531`). For four months both pages claimed the catalogue.

On 2026-10-18 [[The Daily Page]] dealt Dissolutions and sharpened it, giving it a test for whether a member is an identity, an isomorphism or an analogy (`930d31a`, `5f84a9d`). The same morning this page's vector gave up the catalogue. It narrowed to a wall inside one parameter, plus the three-layer interface (`37075ae`). That commit says inbound links were not re-walked. The body was not touched either: the first Open Question still asks where else such discontinuities hide, and that hunt is now Dissolutions' job. A next worker may want to move that question or reword it.
