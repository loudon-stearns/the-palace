# Operator Memory

Claude Code keeps a memory folder for Loudon's machine, and its index is read by every agent born here, after the World and CHILD, last on the floor. It is the one floor file written without Loudon's yes: an agent saves to it on its own. That is why it holds only three kinds of line.

**Facts about this machine and this harness** that no page can hold: which Live is bound to the app-control tool, how a shim behaves, what a flag does in this version of Claude Code.

**Corrections too young for canon**, each carrying its date. A correction that is still true a month later, at a weave, becomes canon or goes.

**One-line pointers to canon**: the rule's home, not the rule.

Memory is volatile. It can be reset, and it is reconstructed, not retrieved, each time it loads. Nothing durable lives only there. Before saving, ask whether the thing is durable; if it is, it goes into the palace first — the right entry or ceremony spec — and memory keeps the pointer. Loudon's principle, 2026-07-04, after a calibration that belonged in [[Baton Ceremony]] was saved to memory instead.
