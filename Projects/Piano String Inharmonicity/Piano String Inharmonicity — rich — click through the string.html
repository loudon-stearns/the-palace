A click through the string

A string at A2, 110 Hz. The section says its whole behaviour fits in one impulse response, so convolution can make it. We build that response one ring at a time, then test whether the string really is linear and time-invariant. Silent until you press a button.

One ring

Strike a single mode of the string and it rings at one frequency and dies away. That ring is one term of the section's impulse response: a sine, fading exponentially.

h₁(t) = A · e−αt · sin(2πft + φ)
(the response) = (a strength) × (a decay, fading at rate α) × (a sine at frequency f, starting at phase φ).

A ring for every partial

Add forty of them, one per partial, tuned by the formula. Every partial starts at the top of its cycle, so with B = 0 they all line up again once a period, and the click comes back whole every 9.09 ms. Raise B slowly. The high partials now run faster than the period, so each return of the click arrives with its high partials early and smears into a falling chirp, a little more on every trip, until by the top of the slider the click is spread across the whole period. That smear is dispersion, seen in time instead of as stretched partials.

h(t) = Σ An · e−αnt · sin(2πfnt + φn)
(the string's whole response to a click) = the sum, over every partial, of (its strength) × (its decay) × (a sine at its stretched frequency). Here φn = 90° for every n, and higher partials decay faster: αn = 2.5 + 0.02·n² per second.

One partial alone is step 1. B = 0 brings every return back to the same click.

Convolve anything with it

Now send any sound in. Convolution places a copy of the string's response at every instant of the input, scaled by the input there, and adds them up. A click gives back the response itself; three clicks give three overlapping rings; a burst of noise excites every partial at once.

y(t) = (x ∗ h)(t) = ∫ x(τ) · h(t − τ) dτ
(what comes out) = the input convolved with the response: for every moment τ, (the input then) × (the response, started then), all added.

A single click as the input is step 2.

Is the string linear and time-invariant?

The test. The string here is no longer a convolution: it is forty resonators, one per partial, each a filter run sample by sample on the input, a different computation from the formula for h(t). If the section is right, that string and the convolution with h(t) give the same output, and the string passes the four checks below. There are two dials. B is dispersion. Drive makes each partial go sharp when it swings wide, as a real string's tension rises when it is struck hard. Move each, and watch which one breaks the checks.
