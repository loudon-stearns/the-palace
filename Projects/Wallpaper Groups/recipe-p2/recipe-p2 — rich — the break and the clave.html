The break and the clave

Cook the tresillo by the recipe, break one hit as the section says, then set the son clave beside it. Last, test whether the clave is one break from anything this recipe can make. Sound starts only when you press play; changing step stops it.

the loopred ring = a hit with no partner eight steps away
the loop on the clocksolid line = a hit and its partner eight steps on
pairs split by a map = the hits to add or take away before the map lands the loop on itself
(for the recipe's map, n → n + 8, count the step pairs eight apart that hold exactly one hit) is (how far the loop is from anything the recipe can make). For a mirror, n → c − n, the same count says how far it is from a mirror. 0 means the map already lands the loop on itself.
100 BPM, sixteenth-note steps, numbered 1 to 16. One wooden tone at one level for every loop; the cooked and broken loops have six hits, the claves five, so the claves are a hit lighter per bar. A quiet tick marks each beat; the tick button turns it off.
