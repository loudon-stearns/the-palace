Everything the drive and the palace already know, before you tell me the eras

Each bar is a folder or a palace page that looks like a work. Its length is the span of its files' dates, read without downloading a single file. Amber means a guess from file dates; blue means the palace or git already holds it; red means nobody knows yet. File dates say when a file was last touched, not when a thing was made, so every amber bar is a question for tomorrow. Drag to pan, scroll to zoom, click a bar.
