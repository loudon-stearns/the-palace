The hands move where the scan reads, not how fast it runs. Each is a fixed function of the read point, so a frozen setting is just a different surface: it re-weights the same frequencies m·ω₁ + n·ω₂ and never adds new ones. Locked, everything stays harmonic. Moving a hand is what makes it a gesture rather than a preset.

The Hopf map takes a point (z₁, z₂) on the 3-sphere and keeps two things: the balance |z₁|² − |z₂|², which becomes height, and the phase difference arg z₁ − arg z₂, which becomes longitude. It throws away the shared phase, and that discarded circle is the scan itself running through time. So each point on this sphere names one orbit of the scanner.

Every band has the same width in height, and by Archimedes' hat-box theorem equal height means equal area on a sphere. Every lock, simple or complex, gets the same amount of room.
