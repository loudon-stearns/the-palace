The ear sheet

One sitting in Live. Each ladder is a folder of presets that change one setting a step at a time. Load the first rung, switch on hot-swap, hold or repeat a note, and arrow down. When the sound changes character, pick that rung below. Leave a band blank and it keeps the factory-usage guess.

Rungs outlined like this are where Ableton's own presets divide into fifths — the provisional fences you are moving.

Z00 · the slot decoder

Load Z decoder/Z00 slot decoder.adv. Open the Matrix tab, then MIDI, then MPE. On the Filter 1 Freq row each source shows a small percentage. Type the percentage you see next to each source (blank if it is not there).
