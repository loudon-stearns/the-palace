Does inhibition make the rhythm?

The page says one neuron firing suppresses others, and that inhibitory networks make competitive patterns and syncopation: a beat from what is prevented from firing. This builds that network, a steady trigger and a few leaky nodes, and walks up from one node on every trigger to a test that takes the inhibition away and counts what the rhythm loses, beside a control where the same gaps come from chance. Five steps. Nothing plays until you press Play.

V ← λ·V + w  ·  fire when V ≥ 1, then V = 0  ·  a firing node takes g from every other: Vj ← Vj − g
On each trigger a node keeps λ of its charge (λ = 0.85 here, the leak) and gains its drive w. It fires when the charge reaches 1 and starts again from nothing. With inhibition, the node that fires first pushes every other node down by g; a node it pushes back under 1 in the same trigger is prevented.
four bars of sixteen triggers
the test · 200 random networks, three arms
The rule, written before the first run. Each network has three nodes with drives drawn at random, leak 0.85, inhibition g = 0.5, 64 triggers to settle, then 32 bars scored. Three arms on the same drives: with inhibition; without (g = 0); and chance gaps, the without-arm with each node’s onsets dropped at random until it has exactly as many as the same node with inhibition (40 draws, averaged), so the two differ in where the gaps fall, not how many there are.
  1. T1, inhibition makes syncopation. Syncopation is Longuet-Higgins and Lee’s count on a 16-step bar (a note followed by a rest on a stronger position scores the difference in metric weight), per bar, summed over the three nodes. Per network, inhibited minus without. Holds if more networks rise than fall at one-sided sign-test p < 0.05 (ties dropped); T1 fails here if more fall than rise at p < 0.05; otherwise not shown. Chance is a coin per network.
  2. T2, the gaps are not chance. Entropy of each node’s inter-onset intervals, averaged over nodes: inhibited minus chance gaps. Holds if inhibited is lower (more regular) in more networks at p < 0.05; wrong if higher.
  3. The page’s “rhythm as negative space” holds in this model only if T1 and T2 both hold.
The first run drew drives from 0.18 to 0.9, under 1: each node needs several triggers to fire, so without inhibition it already divides the trigger. That is the run the rule was written for. After it, a second run was added with the rule unchanged: drives from 1 to 2, the page’s “a single trigger … reaches”, where every trigger alone would fire every node.
