# Palace Enchantment — Context

[[Palace Enchantment]] was born on 2026-03-25 at 496 lines, as the vitality ceremony set against the [[Swarm Weave]]'s correctness ceremony (`4dbb574`). It is now more than twice that. Almost nothing has been taken out. It grew the way a lab notebook grows: each practice session's findings were added below the spec, and the spec above was patched in place.

## How it grew

- **First practice, 2026-03-31.** The two enchantments, of [[Hilaritas Generator]] and [[Lateral Access]], came in with the SPONT5 deposit (`dff1a55`). The finding about the synthesis block names its own fix as "applied to Architecture section above". That is the pattern ever since: the story stays in the findings, the result moves into the spec.
- **Second and third practice, 2026-04-01.** About 350 lines arrived on 2026-04-07 inside a Weave commit (`c2dd361`). They brought Free Enchantment, the inner/outer architecture, limited knowledge of the other, the pre-flight configuration, the coordinator role, tool use, post-dialogue artifacts, true multi-agent isolation, and both findings sections. The commit message speaks only of promotions and links. Whoever reads `git log` for the day this page doubled will not find it named.
- **Voice rules, 2026-05-09.** The six clauses for addressing Loudon came from five rounds of revision on one steward message in the Stage A pilot of [[Project Stewardship System]] (2026-05-03). They landed six days later in a cleanup commit that captured in-flight work before a merge to main (`a5ca537`).
- **July 2026.** A wellbeing pass added the weather check, the closing beat and the growing-edge wording (`781feb3`). Voice embodiment for person citizens was added with Loudon, on the ground that "enchantment is exactly when voice matters most" (`22a9a5d`). Loading a citizen's own memory followed, on his design: "I remember what I said and what I thought, and what they said, but not what they thought" (`f53791b`). That memory file was named `context.md` until the v1.28 Schema Ceremony renamed it `diary.md` (`9f9d1cf`).
- **2026-09-26.** Facts about the agent machinery went to a bundle proof that grows by dated runs, with one pointer line left here (`114d359`). The page no longer has to stay current with Claude Code.

## Reversed in place

- **The opening question.** At birth the page asked "is this alive?" and its agent asked "what does this want to become?" On 2026-03-30 the first became "Enchantment says: *You are alive*" and the second went into the first person (`b54785f`). The link label to Swarm Weave, added on 2026-05-14, still carries the older question: `is-it-alive-vs-is-it-correct` (`a383433`).
- **The order of the context.** The birth put identity first, with orientation as "a brief excerpt from JEWEL or SCHEMA as needed" (`4dbb574`). On 2026-03-30 the order flipped. The JEWEL went to the top and a new synthesis trigger to the bottom (`b54785f`). Identity before task held. Orientation is what moved.
- **The model.** The 2026-04-07 configuration put Haiku on exploratory and single-page runs and Sonnet on deeper dialogue (`c2dd361`). On 2026-07-02 Sonnet became the floor for every scope and Opus the choice for deepening, because a thin inner layer makes a flat voice (`781feb3`). The session-d model note in the findings, from the same 2026-04-07 commit, was not updated. It still calls Haiku appropriate for exploratory and single-page work, so the page disagrees with itself here.
- **Smaller ones.** The `computer:///` link scheme went from "Cowork-chat-only" to "don't use it" when live Cowork mentions were cleared (`df2e3c1`). "Palace To-Do entries" became batons when the To-Do retired (`00961f3`). A prediction that every active entry would have a forward vector "after a few Weave cycles" was trimmed on 2026-10-24 (`a75350e`).

## Where the layers disagree

The pre-flight configuration says the Dialogue Moderator coordinator is "not yet built" (Projects/Palace Enchantment.md § Pre-Flight Dialogue Configuration). That text arrived on 2026-04-07 (`c2dd361`), six days after the Dialogue Moderator page wrote its Active Moderator Protocol as executable steps (`19a93b4`); that commit's own next step was still to run one dialogue with it. Whether a written protocol counts as built, neither page says; check Dialogue Moderator before trusting either. The same commit wrote Limited Knowledge of the Other twice, once as architecture and once as a finding marked "Not yet tested", and both copies remain.

## Why it is shaped so

It is a spec and a record in one file, and the findings sections are dated because they are evidence for the spec above them. [[ELDER]]'s "write what is, not what was" pulls the other way. If the findings ever move out, the open ledger plan proposes this page's tuning ledger for them, not a Context (`_ops/Palace Ceremonies/Palace Ceremonies — sketch — propagation plan.md:181`). That choice is Loudon's. The page has moved twice: from the root to `Palace development/` on 2026-03-30 (`b54785f`), and into `Projects/` on 2026-10-12 because it is typed project (`1ce2d2e`). It went from seed to growing to mature within five weeks of birth (`b54785f`, `03faf97`). The mature stamp was given before the voice, wellbeing and memory layers were added.
