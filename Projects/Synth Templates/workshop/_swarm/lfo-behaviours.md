# Family: LFO Behaviours

The LFO's modes, each on a vibrato or a filter sweep so the difference is audible.

Cards to write (11), in tier order:

## natural-vibrato
- name: Natural Vibrato
- tier: 1
- mode: mono
- classics: 
- essentials (catalog): Dedicated vibrato LFO, sine/triangle, 5 Hz, depth under a semitone, to pitch.
- teaches: The vibrato defaults
- concepts the card must list: ["Vibrato: ~5 Hz, under a semitone; dedicated vibrato LFO"]

## vibrato-fade-in-lfo-attack
- name: Vibrato Fade-In (LFO Attack)
- tier: 1
- mode: mono
- classics: 
- essentials (catalog): Vibrato depth ramps in over 300–800 ms after note-on.
- teaches: LFO attack / envelope → LFO depth
- concepts the card must list: ["LFO attack: envelope \u2192 LFO depth", "Envelope \u2192 pitch LFO depth"]

## mod-wheel-vibrato-depth
- name: Mod Wheel → Vibrato Depth
- tier: 1
- mode: mono
- classics: 
- essentials (catalog): Pitch LFO depth set high, CC1 scales it from zero.
- teaches: Secondary modulation; performance
- concepts the card must list: ["CC1 \u2192 pitch LFO depth"]

## tempo-synced-filter-lfo
- name: Tempo-Synced Filter LFO
- tier: 1
- mode: mono
- classics: 
- essentials (catalog): LFO on cutoff at 1/8, then 1/8 triplet.
- teaches: Sync; triplets loosen the grid
- concepts the card must list: ["Tempo sync; triplets"]

## retrigger-vs-free-lfo-chords
- name: Retrigger vs Free LFO (Chords)
- tier: 1
- mode: poly
- classics: 
- essentials (catalog): Slow filter LFO; play staggered chords with retrigger off (one LFO for all) then on (one per voice).
- teaches: LFO retrigger modes
- concepts the card must list: ["Retrigger vs free; chords with staggered attacks"]

## lfo-pan
- name: LFO → Pan
- tier: 1
- mode: poly
- classics: 
- essentials (catalog): Pad with slow LFO on pan; then per-voice random pan.
- teaches: Autopan; random pan for width
- concepts the card must list: ["Per-note random pan for width", "LFO \u2192 pitch / amplitude / pan / filter"]

## pitch-bend-range
- name: Pitch Bend Range
- tier: 1
- mode: mono
- classics: 
- essentials (catalog): Bend range at whole step, minor third, octave.
- teaches: Bend range
- concepts the card must list: ["Pitch bend range"]

## keytracked-lfo-rate
- name: Keytracked LFO Rate
- tier: 2
- mode: poly
- classics: 
- essentials (catalog): Vibrato with key → rate so no two voices sync.
- teaches: Key → LFO rate for ensemble realism
- concepts the card must list: ["Keytracking or velocity \u2192 LFO rate"]

## velocity-lfo-rate
- name: Velocity → LFO Rate
- tier: 2
- mode: poly
- classics: 
- essentials (catalog): Vibrato with velocity → rate.
- teaches: Velocity → LFO rate
- concepts the card must list: ["Keytracking or velocity \u2192 LFO rate"]

## fast-lfo-into-audio-range
- name: Fast LFO into Audio Range
- tier: 2
- mode: mono
- classics: 
- essentials (catalog): LFO on pitch swept from 5 Hz up past 20 Hz into tone.

- concepts the card must list: ["LFO rate range vs oscillator; LFO into audio rate"]
