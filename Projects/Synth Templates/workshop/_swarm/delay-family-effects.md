# Family: Delay-Family Effects

Delays inside the synth: time, feedback, mix, and the LFO that brings them alive.

Cards to write (11), in tier order:

## simple-delay
- name: Simple Delay
- tier: 1
- mode: mono
- classics: 
- essentials (catalog): Pluck into a synced stereo delay: time, feedback, mix.
- teaches: The three delay controls
- concepts the card must list: ["Delay: time, feedback, mix"]

## feedback-to-the-edge
- name: Feedback to the Edge
- tier: 1
- mode: mono
- classics: 
- essentials (catalog): Delay feedback 0% → 100% → beyond, carefully.
- teaches: Feedback as repeat count; runaway
- concepts the card must list: ["Delay: time, feedback, mix"]

## short-delay-comb-filter
- name: Short Delay = Comb Filter
- tier: 1
- mode: mono
- classics: 
- essentials (catalog): Noise or saw mixed with a 1 ms copy; sweep the time and hear the harmonic series move.
- teaches: Delay time and frequency are reciprocals
- concepts the card must list: ["Comb filter: a short delay is a filter", "Comb filter: delay time and frequency are reciprocals"]

## flanger
- name: Flanger
- tier: 1
- mode: mono
- classics: 
- essentials (catalog): Short delay with feedback and an LFO on delay time; on noise, hats, bright synth.
- teaches: A comb filter in motion
- concepts the card must list: ["Delay time LFO modulation", "Flanger: comb in motion with feedback"]

## phaser
- name: Phaser
- tier: 1
- mode: mono
- classics: 
- essentials (catalog): All-pass stages with LFO; notches not in a harmonic series.
- teaches: Flanger without the harmonic series
- concepts the card must list: ["Phaser: notches not in a harmonic series"]

## chorus
- name: Chorus
- tier: 1
- mode: poly
- classics: 
- essentials (catalog): Several delay lines, each with its own LFO, no feedback, stereo.
- teaches: Ensemble by delay-time modulation
- concepts the card must list: ["Delay time LFO modulation", "Chorus: multiple delays, own LFOs, no feedback"]

## stereo-width-by-detune-and-filter
- name: Stereo Width by Detune and Filter
- tier: 1
- mode: poly
- classics: 
- essentials (catalog): Left and right oscillators detuned, left and right filters set differently.
- teaches: Width without delay
- concepts the card must list: ["Stereo width by L/R delay difference; detune and filter per side"]

## reverb-as-long-release
- name: Reverb as Long Release
- tier: 1
- mode: poly
- classics: 
- essentials (catalog): Same pad with release 0 + reverb, vs long release + no reverb.
- teaches: Release vs reverb
- concepts the card must list: []

## stereo-width-by-l-r-delay
- name: Stereo Width by L/R Delay
- tier: 2
- mode: mono
- classics: 
- essentials (catalog): Same sound, left delayed 0–30 ms vs right; then modulate.
- teaches: Precedence effect; width by delay
- concepts the card must list: ["Stereo width by L/R delay difference; detune and filter per side"]

## comb-filter-for-thinning
- name: Comb Filter for Thinning
- tier: 2
- mode: mono
- classics: 
- essentials (catalog): Static comb on a big distorted sound to fit it in a mix without dulling it.
- teaches: Thinning a spectrally rich source
- concepts the card must list: ["Comb filter: a short delay is a filter", "Comb filtering for thinning a rich source"]

## envelope-follower-delay
- name: Envelope-Follower Delay
- tier: 3
- mode: mono
- classics: 
- essentials (catalog): Phaser or flanger delay time driven by an envelope follower on the input.
- teaches: Envelope follower; auto-wah by delay
- concepts the card must list: ["Envelope follower \u2192 delay time"]
