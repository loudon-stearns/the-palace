# Family: Performance Controls

Standard CCs and keyboard modulations, each as a saved template routing.

Cards to write (10), in tier order:

## velocity-amplitude-and-filter
- name: Velocity → Amplitude and Filter
- tier: 1
- mode: poly
- classics: 
- essentials (catalog): Velocity to amp and to filter cutoff: accents are louder and brighter.
- teaches: The two default velocity routings
- concepts the card must list: ["Velocity \u2192 amplitude; velocity \u2192 filter cutoff"]

## velocity-filter-envelope-amount
- name: Velocity → Filter Envelope Amount
- tier: 1
- mode: poly
- classics: 
- essentials (catalog): Velocity scales the filter envelope depth: brighter attack, same sustain.
- teaches: Velocity → envelope amount
- concepts the card must list: ["Velocity \u2192 filter envelope amount; \u2192 pitch envelope amount"]

## key-filter-cutoff-keytracking
- name: Key → Filter Cutoff (Keytracking)
- tier: 1
- mode: poly
- classics: 
- essentials (catalog): Cutoff follows key at 0%, 50%, 100%.
- teaches: Brightness across the keyboard
- concepts the card must list: ["Key \u2192 filter cutoff"]

## key-pan

- concepts the card must list: ["Key \u2192 pan (piano panning)", "Key \u2192 pan"]

## cc-decay-on-percussive
- name: CC → Decay on Percussive
- tier: 1
- mode: mono
- classics: 
- essentials (catalog): A CC controls decay time on a no-sustain sound: the length knob.
- teaches: Decay as length
- concepts the card must list: ["CC73 / CC72 \u2192 attack / release; CC \u2192 decay"]

## volume-vs-expression-cc7-cc11
- name: Volume vs Expression (CC7 / CC11)
- tier: 1
- mode: poly
- classics: 
- essentials (catalog): CC7 for the mix level, CC11 for phrase dynamics as a percentage of it.
- teaches: CC7 and CC11
- concepts the card must list: ["CC7 volume, CC11 expression, CC72 release, CC73 attack"]

## modulation-template-init-patch
- name: Modulation Template (Init Patch)

- concepts the card must list: ["Modulation template saved as the init patch"]

## cc73-cc72-attack-and-release
- name: CC73 / CC72 Attack and Release
- tier: 2
- mode: poly
- classics: 
- essentials (catalog): CC73 to amp attack, CC72 to amp release: legato vs staccato on one sound.

- concepts the card must list: ["CC7 volume, CC11 expression, CC72 release, CC73 attack", "CC73 / CC72 \u2192 attack / release; CC \u2192 decay"]
