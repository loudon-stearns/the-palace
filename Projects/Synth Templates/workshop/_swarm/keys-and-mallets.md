# Family: Keys and Mallets

Played like a keyboard: fast attack, decay that tells the material.

Cards to write (16), in tier order:

## pluck
- name: Pluck
- tier: 1
- mode: poly
- classics: 
- essentials (catalog): Saw, LPF, filter env decay ~150 ms no sustain, amp decay ~400 ms.
- teaches: The canonical pluck
- concepts the card must list: ["Subtractive: rich wave then filter", "Envelope \u2192 filter cutoff (bite; auto-wah with long attack)"]

## chord-stab
- name: Chord Stab
- tier: 1
- mode: poly
- classics: house / garage
- essentials (catalog): Saw + square, LPF, short amp decay, played as a chord; unison 2.
- teaches: Stabs; chords as one sound
- concepts the card must list: []

## marimba
- name: Marimba
- tier: 1
- mode: poly
- classics: 
- essentials (catalog): Sine + a 4th-harmonic partial, very fast decay, pitch env tiny.
- teaches: Mallet: fast decay, few partials
- concepts the card must list: ["Pluck / strike: release = decay; gong vs marimba"]

## bell

## organ
