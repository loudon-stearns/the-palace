# Family: Pads

Slow attack, long release, movement. Poly; the modulation is the sound.

Cards to write (17), in tier order:

## warm-analog-pad
- name: Warm Analog Pad
- tier: 1
- mode: poly
- classics: Juno-106
- essentials (catalog): Two saws slightly detuned, LPF ~1 kHz, slow filter env, chorus.
- teaches: Slow filter envelope; chorus
- concepts the card must list: []

## string-machine
- name: String Machine
- tier: 1
- mode: poly
- classics: Solina / ARP String Ensemble
- essentials (catalog): Saw, no filter envelope, ensemble/chorus heavy, medium attack.
- teaches: Ensemble effect as the timbre
- concepts the card must list: ["Chorus: multiple delays, own LFOs, no feedback"]
