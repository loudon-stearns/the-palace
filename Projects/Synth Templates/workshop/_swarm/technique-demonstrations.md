# Family: Technique Demonstrations

Not a genre sound: a single technique isolated so you can hear it.

Cards to write (33), in tier order:

## vibrato-lfo-pitch
- name: Vibrato (LFO → Pitch)
- tier: 1
- mode: mono
- classics: 
- essentials (catalog): Sine, sine LFO 5–6 Hz on pitch, depth ±20 cents, delayed onset.
- teaches: LFO to pitch
- concepts the card must list: ["Vibrato: ~5 Hz, under a semitone; dedicated vibrato LFO", "LFO \u2192 pitch / amplitude / pan / filter"]
