# Family: Envelope Shapes

Loudon's envelope library: one amp envelope per shape, on a plain saw through an open filter.

Cards to write (15), in tier order:

## switch-organ
- name: Switch (Organ)
- tier: 1
- mode: poly
- classics: 
- essentials (catalog): A 0, S 100%, R 0; decay does nothing.
- teaches: The instant on/off envelope
- concepts the card must list: ["Switch envelope (organ); percussive organ"]

## percussive-organ
- name: Percussive Organ
- tier: 1
- mode: poly
- classics: 
- essentials (catalog): A 0, D very short, S 80%, R 0.
- teaches: A little bite on a sustaining envelope
- concepts the card must list: ["Switch envelope (organ); percussive organ"]

## standard-sustaining
- name: Standard Sustaining
- tier: 1
- mode: poly
- classics: 
- essentials (catalog): A 0–10%, D 0–10%, S 50–90%, R 0–10%. Blown or bowed: burst then steady.
- teaches: Sustaining instruments
- concepts the card must list: ["Sustaining vs non-sustaining sounds", "Standard sustaining envelope; strings and horns variants"]

## pluck-strike-release-decay

- concepts the card must list: ["Sustaining vs non-sustaining sounds", "Pluck / strike: release = decay; gong vs marimba"]
