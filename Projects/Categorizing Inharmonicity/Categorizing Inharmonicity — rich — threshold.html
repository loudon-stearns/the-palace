When does it leave?

One note at 220 Hz with sixteen partials. We start with the harmonic series alone and end on the page's open question: at what size does each kind of inharmonicity become audibly different from harmonic, and is that the same for every kind? Silent until you press a button. Headphones help.

The harmonic series

Every partial sits exactly on a whole-number multiple of 220 Hz, and the sixteen fuse into one note. The dashed lines are those places, the ghosts every later step measures against. Each partial is 1/n as loud as the first, and every tone in this piece has the same partials at the same loudness, the same envelope and the same first partial, so the only thing that changes is where partials 2 to 16 sit.

One kind, raised from zero

Pick a kind and raise its own number from zero. At zero every kind is step 1's tone. Strike the harmonic tone and this one back to back, raise the slider, and press I hear it leave at the first setting where you can tell them apart. That mark is sighted (you can see the slider), so step 4 measures it again, blind.

Its number at 0 is step 1's harmonic tone.

Six kinds, the same mistuning

Now every kind is set to the same mistuning, so the ruler can't tell them apart. Listen to the six in a row after the harmonic tone. If the page is right that these are kinds and not degrees, they should sound different from one another here, not just more or less out. The table says how far apart their patterns are, in the same cents: a small number means two kinds put their partials in nearly the same places.

Where does each kind leave? A blind test

The open question, asked of you. Pick a kind and start. Each round plays two tones, one harmonic and one not, in a random order; say which one left. Two right answers in a row make the next pair harder, one wrong makes it easier, so the mistuning settles where you are right about seven times in ten. It ends after eight turnarounds, about twenty to thirty rounds, a minute or two. Run as many kinds as you like; the table and the verdict fill as you go.

threshold = the geometric mean of the last six turnaround mistunings
(where you start hearing it) = the middle of the last six places the staircase changed direction. The spread beside it says how much those six disagreed.

One listener, one note (220 Hz, sixteen partials, a 0.8 s fall), one pair of speakers or headphones. The ruler weights partials by loudness; a ruler that counted the farthest partial instead would rank the kinds differently (the table gives that number too). For stretch alone, the laboratory version of this question found the threshold depends strongly on the fundamental (Järveläinen, Välimäki and Karjalainen, 2001), so a lower or higher note may move every number here.
