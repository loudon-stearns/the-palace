# light-round-2026-11-2

the second light enrichment round, fifty pieces

## The rule of this folder

This is the workshop of the second light round, opened by the Concierge for the working session, which is a child. It was started with the Shop's bench (`node Shop/shop.mjs workshop`), so the menu below is the Shop's own and a piece run through `jobs.json` says what made it.

- **Everything is made here.** No file goes into a page's bundle, no `— rich.json` is written and no entry's text is touched until an elder places a piece. A piece here is an unapproved rough.
- **The round is run from [[Light Enrichment]]**: read the page whole as a first-time reader, write the claim and what will make it before making, challenge before commit.
- **The slate** is `candidates.md` (and `candidates.json`): 86 pages to choose fifty from, after reading.
- The first round's workshop is `Enrichment/light-round-2026-11/` and stays as it is.

## Before the first file

Choose the tool for each PART of a piece, not for the piece: what would have been recorded or photographed is generated, what is plainly synthesized or a diagram is built by hand, and the two are edited together. Then write the piece's job in `jobs.json`, with its chain, and run it through the bench:

```sh
node Shop/shop.mjs run "Enrichment/light-round-2026-11-2/jobs.json" <job>     # from the palace root
node Shop/shop.mjs check "Enrichment/light-round-2026-11-2"          # what made each file here, and who has heard it
node Shop/shop.mjs card "<Specialist>"          # one Specialist whole: its command, its speed, what it has not been shown to hold
```

Your own script is welcome. Name it in the chain as `hand: …`, and let a job be one function in it. A brief you hand another maker says what makes the piece, or that the maker chooses from the menu below.

## Where it is heard

Loudon looks and listens on a page's scroll in STIGMERGY. A run presents this folder there by itself: a section on the scroll of each Specialist in the chain, and a link on the scroll of the page a piece is for. Again by hand: `node Shop/shop.mjs present "Enrichment/light-round-2026-11-2/jobs.json"`. Link any file by its palace path, as `[caption](Enrichment/light-round-2026-11-2/file.m4a)`; the app plays sound, shows images and frames a web page from such a link. Plain ASCII filenames with no em-dash keep a web page's URL whole. Presenting another way is welcome when it shows the work better; leave both on the scroll to compare.
