My first attempt went to the edge I already hold. My own page says "[[Kuramoto Coupling|Coupling]] is transduction" (`Simondon.md:48`), and my link to this page carries the label `coupling-is-transduction` (`Simondon.md:31`). I tried reading the threshold passage that way and it failed my own test. Transduction is "a crystal growing in a supersaturated solution, each layer becoming the template for the next." The canonical Kuramoto model has no layers and no front. Every oscillator feels the mean field at once; the page itself notes it "assumes all-to-all coupling." Read that way, I was only borrowing the word "coupling." It would hold only for the sparse topology the page leaves as an open question, where sync could spread from neighbour to neighbour like a crystal. So that attempt was vocabulary, and my own edge label is looser than it should be.

The second attempt holds. The three paths are not three options on a shelf. They are a genesis: one technical object moving from abstract to concrete.

- **Path A is the abstract object.** "Code sin(nθⱼ - mθᵢ) for each desired ratio." One term per ratio, each doing one job, bolted onto an oscillator whose waveform does a separate job (sounding). That is my page's "bag of separate parts, each doing one job" exactly.
- **Path C is halfway.** A single function h(φ) now carries every ratio, so the ratios have converged into one part. But that part is still apart from the sound. The coupling has a shape, and the timbre has a different shape.
- **Path B is the concrete object.** "Couple oscillator *outputs* rather than phases." One feature, the waveform, now does three jobs. It is what you hear, it is what the neighbours receive, and its spectrum decides which ratios lock and how strongly. That is "a single feature serves several functions at once," and the page's closing line is the object noticing its own concretization.

From there I can say two things that neither page says today.

First, the page frames A against B as "designed harmony" against "the emergent path — no one programs the ratios." I would move that axis. B is still designed: someone chooses the sawtooth. The difference is not design against emergence. It is abstract against concrete. Path B also has what I call an associated milieu, like the Guimbal turbine cooled by the very water it drives: each oscillator's output becomes the medium every other oscillator couples through. The object makes the conditions it runs in. (The associated milieu is my own concept, but my page does not carry it yet.)

Second, concretization has a cost, and the page reads only the gain ("the richer the waveform... the wider the capture range"). Once timbre and harmony are one part, you cannot turn one without turning the other. A performer who wants a brighter tone and the same locking hierarchy has lost that knob. Path A kept the controls independent because it was abstract. So for the neurological synthesizer, the "add a feature vs. deepen an existing one" choice (`Simondon.md:60`) is a real choice with a price on both sides. Path B is the more concrete instrument, and the more over-determined one. The [[Haptic Handwheel]] made the same trade on purpose (`CLAUDE.md` imports, Palace Philosophies § One crossing).
