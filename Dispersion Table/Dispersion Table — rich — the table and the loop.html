The table and the loop

A single stored cycle can be kept two ways. Hold it still and run a reader across it, or send it round a loop past a reader that holds still. Take each alone, then hold them against each other, then make the loop half a sample longer and see what it has to do.

1 · A table, and a reader that sweeps it

A wavetable is one cycle of a wave stored as P numbers. A reader runs across it, one number per sample, and jumps back to the start at the end. The table never changes. Only the reader moves.

2 · A loop, and a tap that holds still

Now put the same P numbers in a delay line and feed its output back into its input. Nothing sweeps it. Each number leaves at the tap, goes straight back in at the far end, and comes round again P samples later.

3 · Both at once, one upside down

Run the table and the loop side by side, and subtract one from the other. Whatever is left is something the loop does that the table doesn't. To show that this test can fail, the loop can also be made one sample longer than the table.

doPlay their difference. Then make the loop one sample longer and play it again.

4 · The test: half a sample longer

The page says the identity is exact only for a whole number of samples, and that a fractional length already puts a filter in the loop. Make the period P + ½. The table reads between two stored numbers, fresh from the stored cycle every time. The loop has to read between samples too, but it reads its own last trip, so whatever that reading does, it does again on every trip. There are two usual ways to read halfway between samples. A straight line between neighbours, which at a half sample is Karplus-Strong's average. Or a first-order allpass, which keeps every level and pays in timing instead.

doPlay the loop with the straight line, then with the allpass. Raise the pitch: the loop gets shorter and reads between samples more times a second.
watchMeasured from the loop: how fast each harmonic dies, and how far it sits from the table's harmonics. The table loses nothing and sits on its grid.
hearThe straight line dulls the loop, highs first, and the table stays bright. The allpass keeps it bright, and at a high pitch its upper harmonics go flat of the table's.
