## Standard Elicitation Questions (Phase 1)

Asked for every category. Adapt language to domain as needed.

1. **Inventory** — What do you own or have regular access to? List everything, even things you barely use.
2. **Primary vs. peripheral** — Which tools are central to your current work? Which are occasional or archived?
3. **Teaching role** — Which do you teach with? Do you teach the tool itself, or use it to teach something else?
4. **Ecosystem role** — How does this tool connect to others in your toolkit? What feeds into it, what does it feed?
5. **Creative use** — What do you make with it? Any notable projects or specific contexts?
6. **Relationship** — What's your current relationship to this tool: fluent, learning, estranged, aspirational?
7. **Missing** — What's in this category that you wish you had, or that you used to have?

## Raw Notes — Synthesizers

*(Session started: 2026-04 — interview complete, entry drafted)*

**Q1 — Inventory (hardware only — software to be done separately):**
- ASM Hydrasynth Explorer
- Sequential Prophet-6
- Waldorf Blofeld (desktop module)
- Blip Blox (old version)
- DSI/Sequential Evolver Desktop (confirmed — separate from Hydrasynth Explorer)
- Nord 3P drum pad synth (Nord Drum 3P)
- Erica Synths drum machine (also a synthesizer — will appear in Drum Machines category too)
- Ableton Push (also MIDI controller)
- Ableton Move (also MIDI controller)

**Q2 — Primary vs peripheral:**
- Central: Hydrasynth, Prophet, Nord
- Occasional/shelf: Blofeld (mostly replaceable with software), Blip Blox
- Deep personal relationship: Evolver

**Q3 — Teaching role:**
- Hydrasynth Explorer: taught with for some clients
- Software synths: primary teaching tool for wide audience
- Hardware teaching mostly via manufacturer hire

**Q4 — Ecosystem role:**
- Setup constantly changing
- Mode 1 (computer-tied): single device → computer
- Mode 2 (hardware only): Push or Move at center
- Mode 3 (deep dive): headphones → synth → preset design
- Building toward a fixed performance configuration
- Nord was acquired specifically for stage visual presence (dynamic drum pad look)

**Q5 — Creative use:**
- Three modes: tracking/teaching (computer), hardware-only sessions, deep preset design
- Live performance goal: keyboard + electric bass + drum pads + vocal FX + Ableton control

**Q6 — Relationships:**
- Prophet: know well, ongoing deep relationship, all-around synth (bass/lead/pad), not ideal for drums
- Hydrasynth: getting fluent, very digital, pairs well with Prophet, much to learn
- Nord: just starting, need to build presets
- Blofeld: love the sound, rarely used, mostly replaceable with software
- Evolver: knows inside and out, loves it, audio in/out, edits very fast

**Q7 — Missing/aspirational:**
- Moog: Voyager XL, Muse, or Subsequent 37
- Something from Teenage Engineering
- Curious about Solar 42
- Would upgrade Evolver to keyboard version given space
- Would upgrade Blofeld to a more advanced Waldorf keyboard version
- General priority: master what exists, then add

**Additional notes captured:**
- Erica Synths machine is central to planned performance setup
- Hardware product building (selling own synth/effects) is a long-term goal after Loudon Live reputation established
- Preset management is an ongoing underinvested project — recognized as critical and enjoyable
- Space constraint: regularly setting up and breaking down; wants a consistent configuration
- Software synths: wants to search plugins folder for stub entry when we get there
- "Loudon Live RTM" series concept: read the manual, expose unusual/cool aspects of each synth
- Teaching philosophy: software >> hardware for reach; hardware teaching mostly manufacturer-sponsored
