## From the Flocking shoot-out — 2026-05-29 — Reynolds boids, interactive-control lens, Sketch tier

1. **d3-force is a relaxation solver, not a kinematic integrator,** and that cut against the brief that named it the "primary lane." d3-force expects forces to add into `node.vx`/`node.vy` each tick, then damps velocity (`velocityDecay`) and cools (`alpha`) toward a settled layout. Reynolds boids keep velocity as persistent state, clamped to a maximum speed and never damped; the naive add-into-vx approach with default decay cooled to a frozen blob and would not match a hand-rolled loop. Changed: to reproduce the Reynolds Euler step exactly, so the three Specimens share one trajectory, `velocityDecay(0)`, `alphaDecay(0)` + `alphaMin(0)`, and a custom force that replaces velocity with the clamped result. Documented inline in the file header. For Reynolds, d3-force is a bare tick driver; the real D3 win is the selection, SVG and interaction grammar.
2. **Naming the steering fields `fx`/`fy` pinned every boid in place,** because d3-force reads them as fixed positions. Cost a confusing minute of frozen boids. Changed: the fields became `steerX`/`steerY`.
3. **Three accumulating forces (`forceSeparation`, `forceAlignment`, `forceCohesion`) broke the snapshot semantics:** d3 runs forces in order over all nodes, so alignment would read velocities separation had already changed that tick. Changed: one force that computes all new velocities from a frozen snapshot (pass 1), then writes them (pass 2).
4. **Wrapping only the position update left edge boids seeing too few neighbours,** and alignment broke at the seam. Changed: the minimum-image delta goes inside neighbour-finding too, and positions wrap in the `tick` handler after d3-force applies `x += vx`.
5. **The browser-pane harness used to verify [[Flocking]] never fired `requestAnimationFrame`,** so d3's timers stalled and the sim looked frozen; the files animated normally on a focused tab. Changed: verify by calling `d3.timerFlush()` in a loop to force synchronous ticks, through top-level `function` declarations a classic `<script>` makes global; read computed styles, not screenshots, for colours and fonts. The harness checks render, structure and tokens, not motion feel.
