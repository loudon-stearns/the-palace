### 2026-11-15 — The whole d3 library against just the modules it needs

The zoom-out. On 2026-11-03 d3 7.9.1 began publishing every d3 module as one ES-module file (7.9.2 followed the same day). No new API; what changed is how d3 can be loaded. So a piece can now take only the parts it uses straight from the CDN, each file pinned by a hash in an import map, with no build step. This page draws the same 120-node graph twice: on the left with the shelf's whole d3@7.9.0 script, on the right with only d3-force 3.0.1, d3-selection 3.0.1 and the three small modules d3-force imports.

What a script measured, in headless Chromium 147: the right side fetched 9.3 KB compressed against the left's 89.9 KB, and both landed on the same node positions, to the last bit. A wrong hash in the import map stopped the module from loading. Cold load time could not be told apart in five loads a side; the CDN's noise is bigger than the difference. conform still marks the five module URLs off-shelf, because the shelf doesn't have them yet.

**The question for Loudon: press Draw both. Do the two graphs look the same to you as they settle, and does either one feel slower?**

Behind it is the page's own open question: should a D3 piece load the whole library in one script tag or only the modules it needs? That one is yours to decide. Nobody has seen this.

### 2026-11-15 — The Shop as a relaxed graph: d3-force doing its own job

Two items off the card at once. Until now d3-force had only ever driven boids, which is not its job; here it relaxes a graph, which is. And this is the first D3 chart of palace data: every page in the Shop folder and every page its frontmatter links to, 111 nodes joined by 266 typed links, read by a small script into a JSON file beside the piece. Nothing moves until Relax is pressed. Drag a node and the graph settles again. It can be walked with the keyboard alone (arrow keys to the nearest node, Enter to hear its links, `]` and `[` through its neighbours, a letter to jump), every node has a screen-reader label, and the whole graph is also there as a list.

What a script measured, in headless Chromium 147: edge crossings fell from 7902 to 1383 as it settled, no two nodes overlap, every node stays in frame, and the animated Relax and a 300-step synchronous run land on the same positions. Every keyboard move and every label was checked by key presses and the accessibility tree, and the data file reaches the piece when it is framed the way a scroll frames it. No screen reader has been run on it, and it is a proof, not a finished Piece: no touch handling, no phone, only Chromium.

**The question for Loudon: once it has settled, can you find your way round the Shop by eye? Pick one Specialist you know and say whether its neighbours sit where you would expect them.**

Nobody has seen this.
