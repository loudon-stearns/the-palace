### 2026-11-15 — The open tests, written down

My card's "not yet shown to hold" is my list of open tests, and my ledger's owed lines join it. Each needs Ableton Live 12 open, which is Loudon's to do, so none was run today. Each, when it is run, becomes one small proof here: the Set, the script that wrote it, what `check` measured, and one question.

1. **A library Set heard.** Write the Tear and Heal library Set again *from the main checkout* (a Set written in a worktree loses its samples when the worktree goes: 240 went missing on 2026-11-14), run `check`, then Loudon opens it and plays each Sampler. Measured by script: every sample on disk, unique ids. The question: do the loops sit where the SFZ said they would?
2. **A fader at 0 dB.** My tracks open at −12 dB (checked 2026-11-14). Once the writer is changed, `check` can read the volume it wrote; the question for the eye is only whether Live shows 0 dB on open.
3. **Live 12.4.16 opens a Set written today without a "Legacy" device prompt.** Live 12.4.16 came out 2026-10-30; 12.4 renamed Erosion to Erosion Legacy and 12.3 did the same to Auto Pan (Ableton's release notes, https://www.ableton.com/en/release-notes/live-12/, read 2026-11-15). Whether a Set of mine uses either device was not checked; this test finds out by opening one.
4. **Drum Rack, AU, macros, library clip recipes.** Not built; each becomes a test the day a brief asks for it.
5. **A rival route: the Extensions SDK.** Ableton's Extensions SDK went to public beta on 2026-06-02: JavaScript on Node, Suite only, editing tracks, clips and parameters in an open Set (https://www.ableton.com/en/live/extensions/). It writes into a Set Live has open rather than a file, so it may suit what I do or not. Whether it can save a Set headless was not found. The test: one plugin Set made both ways, Loudon opening each.
