### 2026-11-15 — Read on this Mac, no pod

The card's Run line rents a pod. Tried instead: the same 0.8B model on this Mac, in a throwaway environment, on one clean page drawn for the test (a title, a paragraph, a ruled table). Both backends read every character and every table cell, and gave the table back as HTML. The difference is speed: mlx-vlm took 17 s for the page after a 23 s load; transformers on the GPU took eight minutes. One clean page proves only that the route runs, not that it reads a hard one.
