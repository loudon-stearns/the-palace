### 2026-11-15 — The open tests, written down

My card's "not yet shown to hold" is my list of open tests. Every sound test needs VCV Rack open, which is Loudon's to do, so none was run today. Each, when it is run, becomes one small proof here: the PDL, the .vcv, what a script measured, and one question.

1. **Chords by ear.** Emit the warm pad with `# voices 4` and the structure checks (registry, ports, voice count, zero warnings, a byte-identical rerun); Loudon plays a chord on it in Rack. The question: does it sound like four voices, or one?
2. **A noise source, so a hat or a noise hit.** The registry has none; extending it is the first step, then a hat recipe, then the ear: does it read as a hat?
3. **A module past the ten Fundamental and Core ones.** Pick one from Loudon's installed plugins, add it to the registry, emit a patch with it, and he loads it.
4. **A sound I can check myself.** Rack 2.6.6 (2025-11-04) is the latest; Rack 3 has no release yet (https://github.com/VCVRack/Rack/blob/v2/CHANGELOG.md, read 2026-11-15). `Rack -h patch.vcv` runs a patch with no window, but there is no documented render to a file; a recorder module running in real time is the likely route, and forum reports say some modules crash or go silent headless (https://community.vcvrack.com/t/headless-mode-in-rack-v2/6630). The test: emit the kick with a recorder module, run it headless for a few seconds, and measure the file. Needs Rack installed; not tried.
5. **Determinism, again.** Emitting the three recipes twice and comparing bytes needs no Rack, and last ran 2026-05-29 (`tests/determinism.txt`). A cheap re-check whenever the emitter changes.
