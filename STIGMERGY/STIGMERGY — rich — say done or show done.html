SAY DONE, OR SHOW DONE

work is not real until it lands in LOG. three steps: where each deck reads from and what closes a card, one baton walked to its close, and thirty batons closed three ways.

WHAT CLOSES A CARD

each deck reads one source. STATE reads the files as they are now, saved or not. QUEUE reads the board. LOG reads git. the honesty is not in where the present comes from. it is in what is allowed to take a card off QUEUE, and there are exactly four ways.

ONE BATON

catch a baton, then try to finish it by saying so. the reply lands on the board, and the card stays claimed. only a close takes it off, and the close must name a commit git can find. try a hash that doesn't exist.
