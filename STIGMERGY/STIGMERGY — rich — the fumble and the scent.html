THE SCENT IS A LEASE

a live catcher sends a heartbeat, and each beat lays fresh scent, which evaporates between beats. read as an ant, a claim is alive while its scent is above a threshold θ. read as a queue, it is alive while its lease, renewed at each beat, has not run out. the page says these are the same mechanism. when each beat resets the scent to full, that is a derivation, not an experiment:

e−Δt/τ > θ  ⇔  Δt < τ · ln(1/θ) = L
(scent left since the last beat) above (threshold) ⇔ (time since the last beat) under (evaporation time) × ln(1 / threshold) = (the lease)

so the test is the case that can part. real pheromone is reinforced: a deposit adds to what is there. switch each beat to add, let the catcher die, and count the instants where the two readings disagree.

THE LADDER, RUN

forty batons. most catchers finish; some are slow but alive and keep beating; some die mid-move. each row reads the same forty under one rung. a rung earns its place by what it stops losing, and by what it stops calling dead that is only slow.

key: █ done · × lost, counted as done · ? dead, still shown as claimed, unflagged · ! dead, flagged · ~ alive but flagged as dead · ▲ fumbled twice, sent to a person

rung 1 is built and lived in. rungs 2–4 are deferred by design until the scheduled dispatcher makes them live; this step is a model of them, and the catcher numbers are made up to show the shape, not the palace's rates.
