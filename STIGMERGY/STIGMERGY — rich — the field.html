STIGMERGY · THE COORDINATION SCHEMA

THE FIELD

“the trace left by an action stimulates the performance of a subsequent action.” three steps: one mark taken apart, six agents with and without a board, and the gap where the board stops helping.

ONE MARK

a steward at a fork leaves this line on the board and waits. it is one json object on one line of an append-only file. pick a field to read what it does. the names are exact because code reads them; the words inside are for a person.

SIX AGENTS, TWENTY-FOUR TASKS

no agent talks to another. on the left there is no trace of any kind, not even the finished work, so each agent works through its own list and learns nothing from the others. that is the far end, kept there on purpose. on the right each reads the board before it picks, and leaves a claim when it starts and a mark when it finishes. letters are agents at work; a red cell is the same task being done twice.

THE BOARD · claims land 1 tick after the read

THE GAP BETWEEN READING AND WRITING

the board only helps if a claim lands before the next agent reads. here the same six agents run two hundred seeded times at every gap, from a claim that lands at once to one that lands eight ticks late. the flat line is no board at all.
