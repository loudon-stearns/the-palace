Specimen · controls

The browser's furniture, re-dressed

Every control on this card is the bare element with no class. What you see is what an artifact gets for free once it loads controls.css after the tokens: the scrollbar, the chevron, the box, the thumb, the grip, all in the skin.

Scrolling panel

The thumb is a mark, not a bar. It rests dim, wakes under the pointer, and goes accent only while you drag it. The gutter is the page.

A scrolling panel inside a card used to arrive with the operating system's own scrollbar: a light track on a dark page, a rounded grey pill, two arrows nobody asked for.

Now it reads as part of the artifact. Keep scrolling: the panel holds more than it shows, which is the whole reason it scrolls.

Firefox and Chrome read the standard properties; Safari reads the pseudo-elements. Both are kept level by hand in the one file.

Textarea

Resize is vertical only. The grip is drawn in the sheet's colours; the scrollbar inside the box is the same thin mark as everywhere else.

Fields

No spinner on the number: arrow keys and the wheel still step it. The date picker and the select popup follow color-scheme, so they open dark on a dark skin.

Select

The chevron is two hairlines drawn with gradients in a token colour. No icon, no SVG, no hex.

Checkbox and radio

Checked is the house's ● on: accent with the page ringed inside, not a tick. A radio is round because the shape means one-of.

Range

A hairline track and a square thumb that goes accent under the hand. The slider never shows its number; the page writes it beside the label, so the value is text you can read and grep.

Buttons and file

The bare element with no class: a quiet hairline button in the mono eyebrow voice. Most artifacts style their own; this is the floor under them.
