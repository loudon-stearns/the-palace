# Map agent test — creative set (map build 2026-10-23)

Cite every edge you rely on as [Source | relation | Target], spelled exactly as the map spells it. Never name a page that isn't in the map.

C1. RHYMES. Find three pairs of pages that share NO edge in either direction but should be linked — a real find, not a forced one. For each: the evidence in the map's shape (shared neighbours, shared relation types or labels), the relation type you'd propose, and one sentence on why. Then name one tempting pair you rejected as forced, and why.

C2. A MIRROR WALK. Using ONLY `mirrors` edges (either direction), give the shortest route from "Kuramoto Coupling" to "Haptic Handwheel", and then from "Kuramoto Coupling" to "Stoicism". If no route exists, say so plainly.

C3. A DIALECTIC CAST. From the map's `contradicts` edges, cast a 3–4 voice dialectic around one live tension. Each voice must contradict at least one other in the cast by a real edge. Name the tension in one line and say what each voice brings.

C4. A WALK. Someone knows "Granular Synthesis" well and wants to understand "Cooperation Yields Agency". Give a 4–6 stop route, every step a real edge, chosen so each stop teaches the next. One sentence per stop.

C5. A CONSTELLATION on *attention*: 5–7 pages, connected (every page reachable from every other through edges inside the constellation), crossing at least three relation types. Name it; say in two sentences what it shows that no single page does.
