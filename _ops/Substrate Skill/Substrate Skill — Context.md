# Substrate Skill — Context

Most of this page's 67 commits were not decisions about this page. Seventeen are Schema Ceremonies, and [[SCHEMA — Reference]] §5 names this file among the mirrors a ceremony must update (SCHEMA — Reference.md:157,164). Many more are other pages' changes arriving here. That is why the page reads as a set of layers: each section is the latest copy of a rule some other page owns. When the owner changes, this page has to follow, and it has missed at least once. The v1.30 ceremony left the link list at ten types until `103a5ea` added `contrasts-with` and `made-by`.
